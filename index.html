What gets tested? First, SignalTrace makes five small requests to this website to check whether it responds and how long each request takes. It then attempts a download and upload transfer test using Cloudflare's public speed-test endpoints. If your browser blocks those tests, SignalTrace marks them unavailable instead of making up a result.

Speed tests transfer data and contact Cloudflare, which may receive your IP address. Results are estimates for the tested route, not a guarantee of your ISP's advertised speed. The HTTP response check is not an ICMP ping or packet-loss test.
